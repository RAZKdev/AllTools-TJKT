# AllTools TJKT

AllTools TJKT adalah website kumpulan tools praktis untuk membantu siswa TJKT (Teknik Jaringan Komputer dan Telekomunikasi) dalam belajar, latihan, dan troubleshooting dasar jaringan komputer.

## Features

- IP Address Calculator
  - Network Address
  - Broadcast Address
  - Subnet Mask
  - Wildcard Mask
  - Host Range
  - Total Address
  - Usable Hosts
  - IP Class
  - Binary Representation

- Subnet Calculator
  - Network Address
  - Broadcast Address
  - Host Range
  - Number of Hosts
  - Subnet Mask
  - Wildcard Mask
  - Mendukung CIDR dan Subnet Mask

- MAC Address Tools
  - Validasi MAC Address
  - Normalisasi format MAC
  - OUI / Prefix 24-bit
  - Binary Representation
  - Unicast / Multicast / Broadcast
  - Locally / Universally Administered

- Bandwidth & Transfer Time Calculator
  - Estimasi waktu transfer file
  - KB, MB, GB, TB
  - Mbps, Gbps, KB/s, MB/s

- Data Unit & Base Converter

- TJKT Quiz

- Network Reference
  - OSI Model
  - TCP/IP Model
  - Common Network Ports
  - Network Protocols

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Termux untuk development dan testing lokal
